# WhereDidItGo

A personal expense tracking application built with Java 21.

The goal of the project is to build the application progressively, starting with
plain Java and later introducing Spring Boot and a React frontend.

## Tech Stack

### Backend

- Java 21
- Maven

### Frontend

- React
- TypeScript
- Vite

### Planned

- Spring Boot
- PostgreSQL

## Project Goals

- Track personal expenses
- Organize expenses by category
- View spending over time
- Eventually manage budgets and financial statistics

This project is also being used to explore Java development and progressively
introduce Spring Boot concepts.
